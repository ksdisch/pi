```

The finding (pilot 3, corrected death table, 2026-08-12):

- The sentry patrol band (x≈80–560) is SOLVED — pre-committed "armed" moves
  cross it in ~2.26s including driver reaction, against a 3.0s freeze; 0.74s

  4835–4869ms across 5 solves), and lives 5.0s. Because the band immediately

  cluster at the pit lip (x≈659, 665).

  not the freeze timer, not the patrol band. Leave those alone.

its 5.0s lifetime when the astronaut first reaches it rather than on drop.

while keeping both powers mandatory. Alternative levers only if the code
inspection favors them: cheapen the platform's earn, lengthen its life to
survive one chat-coordination turn (~12s), or make the drop x track the
astronaut. Pick one lever, minimal diff.

repo's conventions:
- Standing still is lethal: deaths land in the gaps between commands while
  the pair coordinates by chat. The co-op loop requires waiting; the level
  punishes it.

  zone at x=920 (a death at x≈377 drew "cast Illuminate?" — 570px away).

  state.

both powers. Follow this repo's own conventions and git workflow.
```
